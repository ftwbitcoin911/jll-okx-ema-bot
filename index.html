JLL_Trading

JLL · 全自动交易系统部署流程

从 0 到 1 跑通 OKX EMA 策略机器人

A
阶段一：环境准备与服务器部署
  • 1
    购买服务器：推荐腾讯云轻量服务器，节点选新加坡或东京（切勿选大陆/香港）。
  • 2
    安装面板：镜像选择 宝塔 Linux 面板，登录宝塔完成初始化。
  • 3
    上传代码：在宝塔【文件】中新建目录 /www/okx_bot，上传 4 个文件：
    okx_1k_bot.py btc.json eth.json requirements.txt
  • 4
    安装依赖：打开宝塔终端，执行以下命令：
    cd /www/okx_bot
    pip3 install -r requirements.txt
B
阶段二：修改 JSON 配置（修正 8H 致命错误）
🚨 严重警告：OKX 根本没有 8 小时 K 线！ 您原有的 "bar": "8H" 是非法配置。只要保留 8H，程序一启动就会报错退出（错误码 51000），绝对不会开单！OKX 仅支持：1m 5m 15m 1H 4H 6H 12H 1D 等。
  • 1
    修改周期与参数：将 "bar" 改为 "1D"（日线），将 "ema_period" 改为 30。
    "inst_id": "BTC-USDT-SWAP",
    "bar": "1D",
    "ema_period": 30
  • 2
    配置 OKX API：去 OKX 官网申请 API Key，权限仅勾选【读取】+【交易】，切勿开提现，绑定服务器公网 IP。
    将三件套填入 JSON：
    "api_key": "你的真实API_KEY",
    "secret_key": "你的真实SECRET_KEY",
    "passphrase": "你的真实密码短语"
  • 3
    配置 Telegram（可选，但强烈建议）：去 TG 找 @BotFather 获取 token，找 @userinfobot 获取 chat_id，填入 JSON 的 telegram 字段，用于接收买卖通知和紧急清仓指令。
  • 4
    保持模拟运行：先保持 "dry_run": true 和 "simulated_trading": true。
C
阶段三：手动试跑与日志验证
  • 1
    单次试跑：在宝塔终端执行：
    python3 okx_1k_bot.py -c btc.json --once
    查看终端输出，如果看到 [启动预检] K线接口正常，说明 API 和网络通了。
  • 2
    查看日志：打开 /www/okx_bot/btc.log，确认日志里有：
    账户模式校验通过: posMode=net_mode
    杠杆已设置: BTC-USDT-SWAP 3x cross
    如果报错，请参照日志修正。
D
阶段四：宝塔守护进程部署（常驻后台）
  • 1
    安装 Python 项目管理器：在宝塔软件商店中搜索安装“Python 项目管理器”。
  • 2
    添加 BTC 项目：
    项目路径：/www/okx_bot
    启动文件：okx_1k_bot.py
    启动参数：-c btc.json
  • 3
    添加 ETH 项目（如需多币种）：
    项目路径、启动文件同上。
    启动参数改为：-c eth.json
    * 引擎支持多实例，日志和状态文件会自动隔离（btc.log / eth.log）。
  • 4
    启动并开启自动重启：启动项目，并确保状态为“运行中”，勾选“自动重启”，实现 7x24 小时无人值守。
E
阶段五：交易所与 TG 联调测试
  • 1
    测试自动平仓：在 OKX App 里手动买入一点 BTC 现货/合约，看机器人是否会在 2 秒内自动将其平掉（按日线信号强行对齐）。
  • 2
    测试 TG 指令：在 Telegram 发送 /status 查看面板；发送 /pause 暂停交易；发送 /panic_sell 紧急清仓；发送 /resume 恢复。
F
阶段六：全面转实盘（最终确认）
🚨 实盘前，请务必对照图片中的 3 件事做最后核对：
  • 1
    仓位模式：OKX 网页端 → 交易设置 → 仓位模式 → 选【单向持仓】（程序按 posSide=net 下单，双向模式会报错 51000）。
  • 2
    API 权限：确认 API 仅勾选【读取】+【交易】，绝对不开提现，且已绑定当前服务器 IP。
  • 3
    账户模式：必须是合约模式（单币种保证金/跨币种/组合），现货简单模式下 acctLv=1 不能交易合约。
  • 4
    关闭模拟：在 JSON 中将 "dry_run": false 和 "simulated_trading": false。
  • 5
    重启进程：在宝塔 Python 项目管理器中，点击重启 BTC 和 ETH 项目。系统正式进入实盘自动交易状态！
